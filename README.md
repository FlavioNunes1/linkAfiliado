🔗 Desconto Certeiro – Página de Links Afiliados

Affiliate Links Landing Page

🇧🇷 Português

📌 Sobre o Projeto

O Desconto Certeiro é uma landing page de links afiliados desenvolvida para centralizar ofertas e direcionar usuários para plataformas de e-commerce.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, sem frameworks ou bibliotecas externas.

O objetivo é:

Centralizar links afiliados em um único lugar

Criar uma interface moderna e responsiva

Melhorar conversão e experiência do usuário

Ter total controle visual e estrutural da página

🛠️ Tecnologias Utilizadas

HTML5

CSS3 (Custom Properties / Variáveis CSS)

JavaScript (ES6+)

Design responsivo

Suporte automático a Dark/Light Mode

🎨 Recursos Técnicos

Layout centralizado com CSS Grid

Design minimalista com efeito glassmorphism

Variáveis CSS para fácil personalização

Detecção automática de tema do sistema (prefers-color-scheme)

Atualização automática de ano via JavaScript

Estrutura leve e performática

🛒 Plataformas Integradas

A página direciona para links afiliados das seguintes plataformas:

Shopee

Magazine Luiza

Mercado Livre

SHEIN

TikTok

Instagram
